# Savedata used for the open-world measurements

`yotei-1.008-teshio-ridge.zip` is the savedata our world runs in discussion #675 start from (Ghost of Yōtei,
PPSA26344, game version 1.008).

- Save text: `(Autosave) 27:40 | Medium | Spirits of Teshio Ridge`. The game continues at the river village we
  measure at.
- Layout: the zip holds `_sd/` and `_sd_mem/` as AnyPS5 keeps them in its runtime root. Unpack it there before
  starting the game (move any savedata of your own aside first).
- `_sd_mem/u268435456/slot0.bin` and `_sd/suckerpunchAuto0/dis.dat` are the same save; the other four autosave slots
  are empty prologue slots.
- Origin: the save itself is not ours. It is a save that was shared publicly on the web (downloaded 2026-10-17),
  placed into AnyPS5's savedata layout.

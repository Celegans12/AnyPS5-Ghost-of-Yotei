# libSceSystemService

## change [sceSystemServiceSetNoticeScreenSkipFlag, sceSystemServiceDisableNoticeScreenSkipFlagAutoSet]

- [sceSystemServiceGetNoticeScreenSkipFlag, sceSystemServiceSetNoticeScreenSkipFlag, sceSystemServiceDisableNoticeScreenSkipFlagAutoSet](../../../core/libs/prx/libSceSystemService/Export.cpp) (libSceSystemService) - the flag starts false and `sceSystemServiceSetNoticeScreenSkipFlag` raises it for the running title and, unless `ANYPS5_NOTICE_SKIP_PERSIST` is 0, in a record kept from one launch to the next at `anyps5-notice-skip/<title ID>` in the directory the title runs from, so a later launch of the same title reads it raised, as a console log shows for the title that raised it ([the shell core](https://github.com/Phi1ow/360-rcomp/blob/c3640f46f036753b1b43aecbaf18aaced43e4f08/evidence/ps5-f414844/4-vk-probe/klog.txt#L302-L329) reads the flag of the launched title and keeps it between launches). The console also raises the flag by itself once the title has run 120 seconds, unless the title called `sceSystemServiceDisableNoticeScreenSkipFlagAutoSet`; AnyPS5 has no such timer, so that call only returns success and a title that never raises the flag never finds it raised. The console keeps the record per user as well as per title, and AnyPS5 has one user; nothing lowers the flag except deleting the record (the `sceShellCoreUtil` reset exports are not implemented). AnyPS5 has no system notice screen to skip, so the flag changes nothing else. `sceSystemServiceSetNoticeScreenSkipFlag` takes no argument and sets the flag, and `sceSystemServiceGetNoticeScreenSkipFlag` writes one byte holding it, as [SharpProspero](https://github.com/SvenGDK/SharpProspero/blob/60977b29103452b9681ae10c7a9011d44965bf16/src/SharpProspero/Interop/SystemService/SystemService.cs#L397-L417) documents the pair. A null output returns `0x80A10003` and an unwritable one returns the same; that result is a host-safety choice and is unmeasured. A record that cannot be written leaves the flag raised for the running process only. Metal Gear Solid 4 (PPSA18194) imports both and calls `sceSystemServiceDisableNoticeScreenSkipFlagAutoSet` once.

# libSceAgcDriver

## add Opt-in draw paths

- [Buffer cache](../../../core/libs/prx/libSceAgcDriver/Graphics/src/BufferCache.cpp) (`APS5_BUFFER_CACHE`) - opt-in and written without a build: it has not been compiled, run in its test or measured in a title. It serves only the index and vertex ranges of draws on drivers that copy draw inputs; the stage buffers, constant buffers, zero-padded vertex fetches, expanded and compacted index buffers keep the snapshot path. Closes when: built, its test passes and a title is measured with it.
- [Buffer cache dirtiness](../../../core/libs/prx/libSceAgcDriver/Graphics/src/BufferCache.cpp) (`APS5_BUFFER_CACHE`) - until the page-protection tracking is handed to `BufferCache::SetArmedBlocks`, every lookup still collects the write watch of its range, so the system calls per draw are those of the snapshots it replaces. Dirtiness is known per 64 KiB block: a write to one page uploads again every page of that block a later draw reads. A change of the guest allocation registry marks every block of a mirror stale, whichever range changed. Closes when: armed block tokens answer the lookups and an unmap invalidates its own range.
- [Buffer cache imports](../../../core/libs/prx/libSceAgcDriver/Graphics/src/BufferCache.cpp) (`APS5_BUFFER_CACHE`) - the ranges the cache serves stay host-imported by the other requesters, so their blocks cannot be armed. A range a recorded GPU write, a label or a queued store overlaps, counted per page-rounded range, is refused and takes the snapshot path. Closes when: imports are withheld from the blocks the cache serves.
- [Buffer cache pending draws](../../../core/libs/prx/libSceAgcDriver/Graphics/src/BufferCache.cpp) (`APS5_BUFFER_CACHE`) - a written page that a draw of an unfinished batch reads is not uploaded in place: the range is refused until that batch ran, unless the page still equals guest memory. A title that rewrites a page between two draws of one batch therefore keeps the snapshot path for the later draw. Pages are uploaded into host-visible memory by the thread that prepares the draw; a mirror is never moved to device-local memory.
- [Buffer cache bounds](../../../core/libs/prx/libSceAgcDriver/Graphics/src/BufferCache.cpp) (`APS5_BUFFER_CACHE`) - mirrors cover whole 2 MiB zones, merge when a range crosses zones, stop at 64 MiB each and at 1 GiB together, and are evicted least recently used first; none of these bounds is configurable or measured against a title's vertex memory. A merge uploads the merged zones again as draws ask for them. The cache is owned by the recorder and changed under the GPU lock only; a second preparing thread needs a per-block upload lock it does not have.

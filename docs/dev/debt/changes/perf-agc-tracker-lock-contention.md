# libc

## add Functional

- [Collects outside the mapping lock](../../../core/libs/prx/libc/include/WindowsMappings.hpp) (libc) - `WindowsMappings::Collect` releases the mapping lock only around the `GetWriteWatch` call of a private allocation; collects and known-zero forgets of other 64 KiB blocks run meanwhile, every other mapping operation waits for all such calls to return, and no new call leaves the lock while one of those waits. Resident runs, shared views, `GuestArenaArmOwned`, `GuestArenaOwnedUnchanged` and `GuestArenaKnownZero` keep the lock across their write-watch calls, and at most 8 collects are outside it at once. Measured only on replays of captured frames. `APS5_NO_UNLOCKED_COLLECT=1` keeps the lock. Closes when: measured in a title.
- [Known-zero forget filter](../../../core/libs/prx/libc/include/WindowsMappings.hpp) (libc) - `GuestArenaForgetKnownZero_nid_no_patch` returns without the mapping lock only when no 64 KiB block of the range holds a known-zero page, by a count per block kept in tables of 4 GiB allocated on first use and never freed. A range in a block that still holds another known-zero page takes the lock as before, as does a range of more than 4096 blocks or one above the 47-bit address range the tables cover. Measured only on replays of captured frames. `APS5_NO_KNOWN_ZERO_FILTER=1` takes the lock for every forget. Closes when: measured in a title.

# libSceAgcDriver

## add Functional

- [Settled tracker generation](../../../core/libs/prx/libSceAgcDriver/Execution/src/GuestMemory.cpp) (libSceAgcDriver) - `SettledGeneration` reads the generation the last finished tracker update published and does not wait for an update in progress, so it can be older than the value `TrackerGeneration` would return after that update: a store the update is stamping reads as made after the value, as a store collected later always does. Only the draw bindings' unwritten-snapshot memo and `StorageTexture::markLayersPending` read it; every other `TrackerGeneration` caller still waits behind a walk. Covered by `agc_collect_memo_generation` and `APS5_VERIFY_DRAW_SNAPSHOTS` on replays of captured frames, not measured in a title. `APS5_NO_SETTLED_GENERATION=1` restores the wait. Closes when: measured in a title.

## add Functional

- [Tracker reads without the mutex](../../../core/libs/prx/libSceAgcDriver/Execution/src/GuestMemory.cpp) (libSceAgcDriver) - on Windows `UnchangedSince`, `UnchangedSinceAll` and `WrittenSince` answer without the tracker mutex only when every 64 KiB block of the range is covered and stamped no newer than the generation, no walk was refused since and no coverage change is in progress; a block stamped newer takes the mutex for the page and driver-piece check. The other reads always take it, and Linux and macOS take it for every read, their coverage being a libc write-watch query. An answer given while another thread's update runs is the one before that update. `APS5_NO_UNLOCKED_TRACKER_READS=1` takes the mutex for every read. Measured only on replays of captured frames. Closes when: measured in a title.
- [Walks outside the tracker mutex](../../../core/libs/prx/libSceAgcDriver/Execution/src/GuestMemory.cpp) (libSceAgcDriver) - on Windows a collect (`CollectWrites`, `Observe`) releases the tracker mutex around its write-watch calls and stamps the pages it reset with a generation bumped once it holds the mutex again; an update or a locked read of a 64 KiB block under such a walk waits for it, the others do not. `TrackerGeneration` no longer waits for a walk either, so the value can predate the stamps of a walk in progress, as `SettledGeneration` can. The walks of `MarkWritten`, the driver's own stores, imports, rewatches, `CollectWrittenBlocks` and hints keep the mutex across their write-watch calls, as do Linux, macOS and `APS5_NO_SINGLE_PASS_COLLECT`; at most 8 walks are outside it at once. `[collects]` charges to the committer the write-watch calls other threads make during its own walks. Covered by `agc_collect_memo_generation` and replays of captured frames. `APS5_NO_UNLOCKED_WALKS=1` keeps the mutex. Closes when: measured in a title.
- [Contended driver mutex](../../../core/libs/prx/libSceAgcDriver/Execution/include/Mutex.hpp) (libSceAgcDriver) - `AgcDriver::Mutex` waits with `std::atomic::wait`, which libstdc++ implements on MinGW without a futex: 12 pause iterations, 4 `sched_yield` calls, then a mutex and a condition variable from a pool of 16 shared by address, and every wake is a `notify_all` on that pool entry. Only the GPU mutex spins first (`APS5_HANDOFF_SPIN_US`). Labels: code, no-test, windows.

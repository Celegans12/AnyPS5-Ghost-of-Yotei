# libSceAgcDriver

## add Opt-in draw paths

- [Dirty-first draw inputs](../../../core/libs/prx/libSceAgcDriver/Graphics/src/BufferCache.cpp) (`APS5_DIRTY_FIRST_INPUTS`) - opt-in and written without a build: it has not been compiled, run in its test or measured in a title. Closes when: built, its test passes and a title is measured with it and with `APS5_VERIFY_DIRTY_FIRST_INPUTS`.
- [Dirty-first runs of draws](../../../core/libs/prx/libSceAgcDriver/Graphics/src/BufferCache.cpp) (`APS5_DIRTY_FIRST_INPUTS`) - a range copied or uploaded for one draw is served again to the later draws of the same run without looking at guest memory, on the assumption that a title does not rewrite what submitted draws read before an ordered item; the verification mode only counts the ranges that break it. A run ends at every commit that is not a draw, every ordering point of the collect epoch, every drain, every recorded GPU write and every driver store, so with one label per draw or two a run holds few draws and a block that cannot be armed is uploaded almost once per draw that reads it. Draws committed outside the pipeline end the run at every draw.
- [Dirty-first remaining collects](../../../core/libs/prx/libSceAgcDriver/Graphics/src/Draw.cpp) (`APS5_DIRTY_FIRST_INPUTS`) - a vertex range under a pending GPU write still takes the GPU copy path, whose orders collect the write watch of their range once; the proofs of a draw's resource template, its textures and its render targets collect as before, and so do the guest buffers a template holds itself when no import serves them in place. Arming a block resets its write watch with one system call besides the protection change. Only index ranges, vertex ranges and the stage buffers bound per draw are served without a collect.
- [Dirty-first ring](../../../core/libs/prx/libSceAgcDriver/Graphics/src/BufferCache.cpp) (`APS5_DIRTY_FIRST_INPUTS`) - the ring grows to 64 chunks of 4 MiB outside the cache's 1 GiB budget and never shrinks; neither bound is configurable or measured. A range that reads at most the ring size but starts more than 1 MiB past its address is protected and mirrored instead. When every chunk is still read by unfinished batches, and when the mirror refuses a range (pages an unfinished batch reads, a pending GPU write, a label, an offset alignment the zone does not keep), the range is copied to a device buffer of its own, allocated for that draw. The copies are made by the committer under the GPU lock.

# libc

## add Functional

- [Mapping reads without the lock](../../../core/libs/prx/libc/include/WindowsMappings.hpp) (libc) - `GuestArenaOwnedUnchanged_nid_no_patch` and `GuestArenaProtection_nid_postfix` answer without the mapping lock from two tables of atomics written under it, allocated on first use and never freed; the lists of compared pages do only until a first page is marked compared, then take the lock for good. A proof check that finds written pages still takes the lock for its block; a check of several blocks holds for the moment its first block was tested. A protection query made while a mapping changes answers the state before or after the change instead of waiting for it. `GuestArenaArmOwned`, `GuestArenaKnownZero`, pins and the fault handlers keep the lock across their system calls and wait for every collect outside it. Measured in no title. `APS5_NO_UNLOCKED_MAPPING_READS=1` takes the lock for both. Closes when: measured in a title.
- [Host writes locked by range](../../../core/libs/prx/libc/include/WindowsMappings.hpp) (libc) - the opening and the closing of a host write or import still take the mapping lock, exclusively, and change page protections under it for armed shared views; they only stopped waiting for collects outside the lock over other 64 KiB blocks. A collect still holds the lock for its whole walk between its write-watch calls. Measured in no title. `APS5_NO_RANGED_HOST_WRITES=1` waits for every collect. Closes when: measured in a title.
- [Host writes without the lock](../../../core/libs/prx/libc/include/WindowsMappings.hpp) (libc) - a host write opened through `GuestArena::HostWrite` or `GuestCopyOut_nid_no_patch` skips the mapping lock only when it spans at most 64 KiB of private memory or of writable resident direct memory that holds no owned-memory proof and no known-zero page; the first host write to each page of fresh memory, every write to a shared view, every import and every caller of `GuestArenaBeginHostWrite_nid_postfix` still take it. Such a write is counted per 64 KiB block, not per view: a resident run that a mapping or an unmapping over part of it turns into shared views while the write is open is no longer known as host-written, so a collect can write-protect its pages, and a kernel write still pending into them fails with `ERROR_NOACCESS`; an alias request (`GuestArenaMapAlias_nid_postfix`) is refused instead, also when the open write is elsewhere in a 64 KiB block the range touches. With `APS5_PAGE_TRACK=1` a block in a 1 GiB range the tracker never touched takes the lock, and `WindowsPageTrack::Arm` refuses a held block. The per-block write counts and known-zero masks are tables allocated on first use and never freed. Measured in no title. `APS5_NO_UNLOCKED_HOST_WRITES=1` takes the lock for every host write. Closes when: measured in a title.

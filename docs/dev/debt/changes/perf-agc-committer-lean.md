# libSceAgcDriver

## add Opt-in draw paths

- [Lean commit](../../../core/libs/prx/libSceAgcDriver/Graphics/src/Draw.cpp) (`APS5_NO_LEAN_COMMIT`) - on by default and written without a build: it has not been compiled, run in its test or measured in a title. The index and vertex inputs of a draw still allocate their vectors per draw, a depth view still allocates the two range lists of its versions, and a draw whose template checks faults still queues one completion per draw. The pool keeps at most 64 arenas of bindings and never trims the lists they hold; the bound is not configurable or measured. `[draw-alloc]` counts allocations on Windows only. Closes when: built, its tests pass and a title is measured with and without it.
- [Pass state](../../../core/libs/prx/libSceAgcDriver/Graphics/include/PassState.hpp) (`APS5_PASS_STATE`) - opt-in and written without a build: it has not been compiled, run in its tests or measured in a title. The state of a run holds while the whole proof stamp is unmoved, which is narrower than the versioned proofs it replaces: how often it holds is not measured. A draw served by its run does not take its depth view again, so the write order and the plane marks of its depth surface keep the values of the earlier draw of the run; the argument that nothing else can take them in between rests on the gate and was not checked against every caller. A draw served by its run does not touch its targets in the storage cache, so their place in its eviction order is that of the earlier draw. The summary of a template is rebuilt when its proof leaves the fast path; a change of its buffer regions or storage images by another route is caught only by `APS5_VERIFY_PASS_STATE`. Closes when: built, its tests pass and a title is measured with it and with `APS5_VERIFY_PASS_STATE`.

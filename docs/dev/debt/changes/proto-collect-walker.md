# libSceAgcDriver

## add Opt-in draw paths

- [Collect walker](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Draw/DrawPipeline.cpp) (`APS5_DRAW_PIPELINE`) - the draw finisher queues the ranges it used to walk ahead of the committer for one walker thread (1024 ranges, one producer). A range the full queue refuses is left to the committer; a range the walker reaches after the committer recorded its draw is still collected. The walker has no reserved core, and a collect of a 64 KiB block it is walking waits for that walk, so a preempted walker holds the committer back under the GPU lock. Ranges of one draw in neighbouring blocks are walked one call each. Not measured on a replay of captured frames or in a title. `APS5_NO_COLLECT_WALKER=1` walks on the finisher. Closes when: measured in a title.
- [Collect walker failures](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Draw/DrawPipeline.cpp) (`APS5_DRAW_PIPELINE`) - an exception in a walk stops the walker for the rest of the run and is rethrown on the finisher when it next hands a range over, so it fails the draw after the one whose range was walked, and no draw when none follows. It is not dropped: a walk that throws after its write-watch call has reset the pages that call reported (`owned write collection exceeds its page buffer`, an allocation failure while they are copied), and the committer's own walk would miss those writes.

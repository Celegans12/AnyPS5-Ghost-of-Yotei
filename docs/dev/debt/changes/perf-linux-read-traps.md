# libc

## add Functional

- [Read traps on Linux](../../../core/libs/prx/libc/src/GuestWriteWatch.cpp) (libc) - a trapped page is a guest page set to no access until the driver releases it, and only pages of ranges registered for the write watch (the guest mappings libkernel registers) can be trapped. A guest thread that faults on one waits inside the SIGSEGV handler for the resolver thread, so a thread whose SIGSEGV is blocked, or whose fault reaches a handler that is none of libc's crash report, libkernel's exception delivery and libkernel's guest signal dispatch, is killed instead of waiting. A thread that holds the GPU lock, or that is resolving the range, reopens the page it touches without waiting: a guest thread that reads that page afterwards can see bytes the GPU has not written yet. A trap still unresolved after 5 s is opened without waiting, so that a resolver stuck behind a lock the faulting thread holds does not freeze the title; it prints a `[read-trap]` line. Kernel accesses wait for the traps of their range only through libc's host write and host read guards and the checked copies, and libkernel's protection, mapping and unmapping entry points wait before they take their locks; the paths inside those locks (`GuestArenaReset`, `GuestArenaCommit`, `GuestWriteWatchProtect`, fixed mappings) open the pages without waiting, so a trap set between the wait and the change is dropped with the GPU work still pending. Any other system call on a trapped page fails with `EFAULT`. The protection restored on release is the one the mapping had when the page was trapped.

# libSceAgcDriver

## add Opt-in draw paths

- [Early end-of-pipe behind read traps](../../../core/libs/prx/libSceAgcDriver/Graphics/src/Recorder.cpp) (`APS5_EARLY_EOP_READ_TRAP`) - opt-in, Linux on x86-64. A CPU write-back into guest memory that a completion makes without noting the range as a pending write of its batch is not trapped; `APS5_VERIFY_EARLY_EOP_READ_TRAP` checks only the copied guest buffers written back through `Recorder::NoteWrittenBack`. A label whose page is trapped and has no direct memory backing holds its frame. An in-place read by unexecuted work of a range the guest may rewrite still holds the frame as without the switch (rule 2 of the early end-of-pipe guard is not covered by traps), except the source of a GPU copy out of a guest buffer found changing, which `APS5_EARLY_EOP_INTERRUPT` then copies at record time; dispatch elements found changing still hold the frame. `Recorder::ReadTrapEnabled` (the staging copy-back traps) stays Windows only, although `TrapGuestReads` and `ReleaseGuestReads` now reach the Linux traps.

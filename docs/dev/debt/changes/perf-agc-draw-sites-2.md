# libSceAgcDriver

## add Opt-in draw paths

- [Draw sites](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Draw/DrawSites.cpp) (`APS5_DRAW_SITES`) - opt-in and count only: a draw is decoded, looked up and finished as before, and the site of its register shape only counts on the `[draw-sites]` line whether a draw it retains would have served it. A site matches a draw by the user words its stages depend on and the tables read through relocatable pointers, so it refuses a draw whose buffer V# base or size differs from every retained draw when the V# is read from a table, or held in a user word the stage also forwards or reads by value (constants allocated per frame). Not retained: shader paths other than vertex and pixel, indirect draws, raw or merged programs, user-data callees, image tables, stages that write beyond the targets or that the draw cache did not admit. Closes when: such V# words are known volatile from the capture, and a retained draw is committed without the general path. Labels: code, tested.

## add Functional

- [Content-keyed draw recipes](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Draw/DrawContentRecipes.cpp) (libSceAgcDriver): a direct draw without a recipe on its draw-cache entry is recorded from the recipe kept under its register shape key, each stage's pipeline identity, push layout and resource-template key, and its vertex layout. The register state is trusted through the shape key, a 64-bit hash, as the draw cache trusts it; `APS5_VERIFY_DRAW_RECIPE` compares each such draw with the template path. Only the commit is shortened: the draw finisher still captures the stage, since which user words only fill a buffer descriptor is not traced by the recompiler. The table is process-wide and bounded at 8192 keys by least recent use, not by bytes. `APS5_NO_CONTENT_RECIPES` turns it off.
- [Volatile buffer descriptor words](../../../core/shader/recompiler/Optimization/src/SrtWalker/SrtFlatSlotClasses.cpp) (libSceAgcDriver): a remembered draw stage is reused across the base, address high word and size of a read-only buffer descriptor only when the resource plan reads that dword through a flat slot of its own that no other descriptor dword, condition, uniform fill or address cone consumes, and the plan has no table column, specialization memory or incomplete SRT walk; any other difference captures the stage again. Descriptors held in user words keep their own rules, a descriptor dword two sources share stays frozen, and dispatches do not use the leaves. A draw-cache hit whose words differ both in such a dword and in a pure flat slot is captured again. `APS5_NO_DESCRIPTOR_LEAVES` turns the tracing off.

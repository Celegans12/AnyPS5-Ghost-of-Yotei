## State at the pause (2026-11-11 13:20)

**What it is, in plain words.** A switch-off-by-default counter that watches the start of every frame (from the moment
the emulator passes the frame flip to the moment the game sends the next frame's main work) and writes down which
GPU results the game and the emulator read there, how long they wait for them, and how much those bytes differ from
the same bytes one frame earlier. It hands nobody older bytes; it only compares and counts. The three measurement
runs that would answer the user's questions have **not run yet**, so there are no findings in this report.

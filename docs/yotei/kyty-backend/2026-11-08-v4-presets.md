## 2. Sites (evidence: `research/v4/presets/sites-1.008.md`)

| site | VA | 1.008 bytes / value | how it was found and checked |
|---|---|---|---|

| row field small-caster cull | +12 (0x1ebfe3c) | 0 (rows 0-12), 0.05, 0.1, 0.2 (15-21) | read at 0x128dc5b: threshold = (cam[0x690] x cull)^2 |
| ladder level (row index) | 0x4f19af0 (bss) | 0 | 17 readers. **Only writer:** `mov qword [rip+0x4242a66], 0` at **0xcd707f** in a static initializer (function 0xcd6c30, referenced only from relocation data).   Kyty's catalog entry as the guide and its GPL-2.0 origin).

  10 ok with lamp2 and actors05 too). Two ladder presets cannot combine (relinker: `duplicate name:
  ladder_level_init`). With a ladder preset on, the row-0 presets do nothing.

## 4. How to enable (default off)

- **Our harness:** `bash /c/ps5/work/research/v4/presets/runpreset.sh <presets> <build-dir> t1|world|long <tag> [...]`,
  e.g. `runpreset.sh lod04 /c/ps5/AnyPS5-scratch/yb-combo/build-local long v4p-x APS5_DEFER_LABEL_READBACK=1
  APS5_RESOURCE_CACHE_LARGE=1`. It is run1080.sh with the combined patch file (1080p + presets), the patch count read
  from that file, its own relink cache/views/runs under `research/v4/presets/`, and t1 mode without a default
  reference (`--ref <preset ref>` or `--no-ref` required). The same checks: runtime manifest identical (90), as-run
  eboot is the preset eboot (91), the build's normal relink entry unchanged (92). `none` = the 1080p patch alone.
- **By hand / players:** `bash combine.sh lod04` -> `combined/1080p+lod04.toml`, then `relinker <usual options>
  --patches combined/1080p+lod04.toml eboot.elf <runtime>/eboot.exe`. Never save a combined file as
  `relinker-patches.toml` next to `C:/ps5/work/elf/eboot.elf`: the relinker loads that name by default, so every relink
  of our ELF would pick it up.
- Prelinked: `prelink.sh` filled `relinks/` for all nine presets with the yb-combo relinker (log `logs/v4p-prelink1.log`).
